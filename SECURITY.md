# Security policy

This repository contains a static public website. There are no user accounts, server APIs, payment flows, or provider credentials in the site.

Report vulnerabilities or accidental disclosure privately to **security@nexuskratos.dev**, identifying the URL and source commit where possible. Do not include credentials or publish sensitive details in an issue. No response-time SLA or bug bounty is currently offered.

Support applies to the current deployed website when deployment is established. No application releases are provided by this repository. Third-party hosting issues should be reported to the relevant provider.
